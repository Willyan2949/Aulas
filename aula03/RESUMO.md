# Aula 03 - Controle de Versão: Git e GitHub (resumo)
- Git guarda o histórico do código; GitHub hospeda o repositório remoto.
- Fluxo: inicializar repositório (git init / VCS no IntelliJ) -> commit das alterações -> conectar ao GitHub (remote, com token de acesso) -> push.
- Fluxo de cada aula: clonar o projeto, desenvolver em um package por aula, commits frequentes com mensagens claras, push no final.
- Atenção: o token com permissões amplas é só para estudo; em projetos reais use permissões mínimas e data de expiração.
## Exercício
- Projeto **AulasJava** com `src/aula03/exercicios/Exercicio01`, `Exercicio02` e `Exemplos`, cada uma com `main`. Depois: git init, commit, conectar ao GitHub e push (esta parte é feita por você no IntelliJ/terminal com sua conta).
