# Aula 05 - Estruturas de Decisão (resumo)
- **if / else if / else**: condição booleana; **operador ternário** `cond ? a : b`.
- **switch**: aceita int, enum e String; sem `break` os cases seguintes também executam; `default` é como o else.
## Exercícios
`exercicios/Exercicio01..10.java`: acesso por idade, desconto, categoria (switch), comissão, horas extras, nota (aprovado/recuperação/reprovado), calculadora (switch), avaliação 1-5, turno do dia, conversão de moedas (cotações fixas no código).
