# Aula 02 - Coleções em Java (resumo)
- **JCF (Java Collections Framework)**: classes e interfaces para armazenar/manipular grupos de objetos (organização, métodos prontos, flexibilidade, eficiência).
- **Interfaces**: Collection (raiz), List (ordenada, aceita duplicatas, acesso por índice), Set (sem duplicatas), Queue (filas), Map (pares chave-valor).
- **List**: add(i, e), get(i), set(i, e), remove(i), indexOf, lastIndexOf, subList.
- **ArrayList**: array dinâmico, aceita null, não é thread-safe.
