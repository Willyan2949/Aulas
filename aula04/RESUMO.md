# Aula 04 - Variáveis, Tipos, Casting, Strings e Scanner (resumo)
- **Variáveis**: tipo + nome; inicializar com `=`; Java não inicializa sozinho; `var` (Java 10+) infere o tipo.
- **Primitivos**: byte, short, int, long, float, double, char (sem sinal, aspas simples), boolean.
- **Operadores**: aritméticos, comparação, lógicos (&&, ||, !), incremento/decremento (++x, x++).
- **Casting**: implícito (tipo menor -> maior, automático) e explícito `(tipo)` (pode perder dados).
- **String**: objeto (não primitivo), aspas duplas; text blocks com """ (Java 15+).
- **Scanner** (java.util): nextInt, nextDouble, nextFloat, next, nextLine; use um `nextLine()` extra após nextInt/nextDouble; feche com close().
- **Comentários**: `//` e `/* */`.
